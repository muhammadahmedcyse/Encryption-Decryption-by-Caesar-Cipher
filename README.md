# Encryption-Decryption-by-Caesar-Cipher
Project Overview:
The program encrypts user provided text using a basic cipher technique and decrypts the encrypted text to recover the original message.

Objectives:
* Understand the basic concepts of encryption and decryption 
* Learn how a Caesar cipher works
* Practice programming logic and string manipulation
* Understand the role of encryption in data confidentiality

Features:
* Accepts text input from the user
* Encrypts text using a Caesar cipher or similar basic technique
* Decrypts the encrypted text
* Displays both encrypted and decrypted outputs
* Demonstrates basic data confidentiality concepts

Technologies used:
* Python 3
* String manipulation
* Conditional statements

How to Run:
* Install Python 3
* Download or clone this repository
* Open a terminal in the project folder
* Run the program:
Python caesar_cipher.py
* Enter the text you want to encrypt
* Review the encrypted and decrypted results.
